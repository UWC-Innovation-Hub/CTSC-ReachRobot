This project creates an interactive 3D learning module in JigSpace to teach students how to work with the CTSC Reach Robot Kit.
It visualizes and explains how different components—such as the traffic light module, buzzer, and motor controls for the car and crane—work together.

The solution aims to make robotics hands-on, engaging, and beginner-friendly for students learning robotics and programming basics.

**🎯 Goals:**
Simplify learning of robot control concepts.
Provide a 3D, step-by-step guide through JigSpace.

**⚙️ Features:**
Reach Kit;
Traffic Light Control;
Buzzer Pin Control;
Motor Control (Car and Crane)
